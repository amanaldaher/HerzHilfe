## 📌 Features

- **Semantic HTML5 Architecture:** Clean document structure with clear landmark tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
- **Editorial Typography:** Styled using Google Fonts pairing Playfair Display for elegant headings and Montserrat for readable body text.
- **Pure CSS Event Slider:** Horizontal event showcase utilizing modern CSS `scroll-snap-type` for smooth touch and wheel scrolling without JavaScript.
- **Dynamic CSS Hover Focus:** Uses the relational `:has()` pseudo-class selector to dim and scale down unfocused cards when hovering over an event.
- **Fully Responsive Design:** Seamlessly adapts across mobile, tablet, and desktop viewports via CSS Flexbox and media queries.
- **Interactive Contact Form:** A clean form layout for inquiries, donations, and volunteer sign-ups.
- **Lightweight & Fast:** Built purely with Vanilla technologies without external JavaScript libraries or heavy UI frameworks.

<hr>

## 🛠️ Built With

- **HTML5:** Semantic structuring and image assets integration.
- **CSS3:** Custom layout system, Flexbox, `:has()` relational selectors, smooth transitions, and responsive media queries.
- **Google Fonts:** Montserrat and Playfair Display typography pairings.
- **Unsplash:** Curated photography assets for non-profit and community themes.
